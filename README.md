# Monst — кабинет аналитики VK

SPA-кабинет аналитики соцсетей на Nuxt 3. Сейчас реализован раздел ВКонтакте на демонстрационных данных.

## Запуск

```bash
npm install
npm run dev
```

Проверки перед сборкой:

```bash
npm run typecheck
npm run build
```

## Разделы

- `/` — сводка по подключённым сообществам и динамика аудитории;
- `/tracker` — онлайн-трекер с графиком активности, сменой периода и моковыми пересечениями аудитории;
- `/communities` — аналитика групп и страниц VK, поиск и сортировка показателей.

Реальные данные пока не запрашиваются: компоненты используют локальные mock-данные и готовы к последующему подключению API бэкенда.
