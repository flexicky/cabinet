# Monst — кабинет аналитики VK

SPA-кабинет на Nuxt 3. Сейчас реализован раздел ВКонтакте на демонстрационных данных.

## Запуск

```bash
npm install
npm run dev
```

Проверки перед сборкой:

```bash
npm run typecheck
npm run build
```

## Разделы

- `/` — сводка по сообществам и динамика аудитории;
- `/tracker` — онлайн-трекер с выбором периода и моковыми пересечениями аудитории;
- `/communities` — аналитика групп и страниц VK, поиск и сортировка.

## Структура

- `pages/` — только композиция экранов и вызов сценарных composables;
- `components/layout/` — оболочка кабинета, навигация и уведомления;
- `components/common/` — переиспользуемые контролы и карточки;
- `components/dashboard/`, `tracker/`, `communities/`, `charts/` — компоненты по разделам;
- `composables/` — состояние и сценарии (`useOnlineTracker`, `useCommunitiesAnalytics`, `useToast` и другие);
- `data/vk-mocks.ts` — единый источник моковых данных;
- `types/` — общие модели аналитики;
- `assets/css/` — стили, разделённые по базовым токенам, оболочке и UI-разделам.

Компоненты отвечают за представление, composables — за состояние и вычисления, а данные отделены от UI. Для подключения API достаточно заменить источник в composables, не переписывая страницы и таблицы.
